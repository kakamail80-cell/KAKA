# 재고 체크 카메라 앱

피어싱 재고 칸 라벨(`A-행-열`)을 카메라로 인식해, 조사 대상 칸까지 **루트(연결선·박스)로 안내**하고, 칸이 화면에 들어오면 자동 촬영한 뒤 개수(0·1·2 / 3개 이상 확인필요)를 기록하는 웹앱(PWA)입니다.

- 작업 폴더: `C:\Users\M\내 드라이브\C_주문리스트_재고매칭\재고체크_카메라`
- Node.js: v24.19.0 (관리자 권한 없이 `C:\Users\M\AppData\Local\Programs\nodejs`에 설치, 사용자 PATH 등록)

## 실행 방법 (PC)

1. 폴더 `C:\Users\M\내 드라이브\C_주문리스트_재고매칭\재고체크_카메라` 에서 터미널을 연다
2. 처음 한 번: `npm install`
3. `npm run dev` → 브라우저에서 http://localhost:5173
4. [엑셀 불러오기] 또는 [칸 직접 입력]으로 조사 대상을 정하고, [파일 테스트]로 동영상을 열어 ▶ 처리

## 태블릿·폰 접속 방법 (PC 서버 방식)

1. PC와 태블릿을 같은 와이파이에 연결
2. 같은 폴더에서 `npm run dev:phone` → 터미널에 표시되는 `https://192.168.x.x:5173` 주소를 태블릿 브라우저로 연다
3. "안전하지 않음" 경고 → [고급] → [계속] (로컬 자체 인증서라서 나오는 경고)
4. [카메라] 버튼 → 카메라 권한 허용

PC 없이 태블릿에서 바로 쓰려면 GitHub Pages로 올려 https 주소를 만드는 방식이 필요합니다 (다음 단계).

## 사용 흐름

1. **[엑셀 불러오기]**: 당일 재고 엑셀(`.xlsm`)의 `재고입력` 탭에서 자사코드에 `[P]`가 붙은 피어싱만 읽어 칸 단위 루트를 만듭니다.
   - 순서: 패널 알파벳 → 행 오름차순 → 행마다 열 방향 지그재그
   - `###`으로 시작하는 행은 제외
   - `_번호`가 붙은 상품(서랍식 보관)은 촬영 없이 **위치만 안내**(주황 박스) → [위치 확인 ✓]
2. **[카메라]**: 확대(근접) 상태로 벽을 따라 움직이면
   - 굵은 녹색 박스 = 지금 대상(라벨을 못 읽어도 격자 위치로 미리 표시)
   - 연결선 = 화면 중앙 → 지금 대상 → 다음 대상들(번호 박스·점선). 화면 밖이면 가장자리 화살촉
   - 하단 카드 = 지금 대상과 방향(`→ 3칸 ↑ 1칸`)
3. **자동 촬영**: 미조사 대상 칸의 라벨이 연속 4프레임 인식 + 라벨 폭 ≥ 화면 폭 5% + 칸 전체가 화면 안 → 촬영 (순서와 상관없이 지나가는 대상도 촬영)
4. **개수 확정 창**: 자동 인식값을 보여주고 `0 · 1 · 2 · 3개 이상(확인 필요)` 버튼으로 바로 확정/수정 → 다음 대상으로
   - [목록]에서 결과를 다시 눌러 수정 가능
   - 파일 테스트(영상) 모드에서는 창 없이 자동 인식값으로 기록하고 계속 진행
5. **[내보내기]**: 사진 zip + `촬영기록.csv` + `조사결과.csv`(엑셀 행, 자사코드, 칸, 옵션명, 상품코드, 개수, 확인필요, 자동추정, 사진)

진행 상태(엑셀 원본, 루트, 결과)는 태블릿 안(IndexedDB)에 저장되어 꺼졌다 켜도 이어집니다. 외부 서버로 보내는 데이터는 없습니다.

엑셀 C열 기록 기능(`src/lib/excel.js`의 `writeStock`)은 구현·검증되어 있으나, 샘플 단계에서는 버튼을 숨겨 두었습니다.

## 구조

| 파일 | 내용 |
|---|---|
| `src/lib/detect.js` | 흰 라벨 검출 (프레임별 자동 밝기 기준 → 닫힘 연산 → 연결 성분 → 가로세로비 2~6.5, 채움비 ≥ 0.6) |
| `src/lib/ocr.js` | tesseract.js OCR. 하이픈이 빠져도 "끝 두 자리 = 열"로 해석(`A516` → A-5-16). 조사 대상 패널 글자만 허용 |
| `src/lib/grid.js` | 패널별 격자 추정 (열=a·x+b, 행=c·y+d, RANSAC). 가짜 격자 방지 조건, 판독 폭 이내로만 추정 |
| `src/lib/pipeline.js` | 프레임 1장 처리 |
| `src/lib/route.js` | 엑셀 대상 → 루트, 목표 칸의 화면 위치·방향 계산 |
| `src/lib/count.js` | 개수 자동 추정(AI 없이, 이웃 칸 중앙값을 빈 서랍 기준으로 비교). 참고값 수준 |
| `src/lib/excel.js` | 엑셀 읽기, C열 기록(해당 셀만 교체, 매크로·서식 보존) |
| `src/lib/store.js` | IndexedDB 저장(사진, 조사 진행 상태), zip/csv 내보내기 |
| `src/App.jsx` | 화면, 루트 안내, 자동 촬영, 개수 확정 창, 시연 영상 녹화(개발 전용) |

### 개수 자동 인식 (AI 없이)
