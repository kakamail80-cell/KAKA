# 재고 체크 카메라 앱 (1차)

피어싱 재고 칸 라벨(`A-행-열`)을 카메라로 인식해 대상 칸을 화면에 표시하고, 가까이 가면 자동 촬영·저장하는 웹앱(PWA)입니다.

- 작업 폴더: `C:\Users\M\내 드라이브\C_주문리스트_재고매칭\재고체크_카메라`
- Node.js: v24.19.0 (관리자 권한 없이 `C:\Users\M\AppData\Local\Programs\nodejs`에 설치, 사용자 PATH 등록)

## 실행 방법 (PC)

1. 폴더 `C:\Users\M\내 드라이브\C_주문리스트_재고매칭\재고체크_카메라` 에서 터미널을 연다
2. 처음 한 번: `npm install`
3. `npm run dev` → 브라우저에서 http://localhost:5173
4. [참고 영상] 버튼(개발 모드 전용) 또는 [파일 테스트]로 동영상을 열고 ▶ 처리

## 폰 접속 방법

1. PC와 폰을 같은 와이파이에 연결
2. 같은 폴더에서 `npm run dev:phone` → 터미널에 표시되는 `https://192.168.x.x:5173` 주소를 폰 브라우저로 연다
3. "안전하지 않음" 경고 → [고급] → [계속] (로컬 자체 인증서라서 나오는 경고)
4. [카메라] 버튼 → 카메라 권한 허용

## 화면

- 상단 바: 격자 ON/OFF · 판독 수(OCR 채택/검출 라벨) · 프레임 처리 ms
- 회색 박스: 검출된 라벨 / 하늘색: OCR로 읽은 라벨 / `*`: 격자 위치로 추정한 번호
- 녹색 굵은 박스: 대상 칸
- 자동 촬영: 대상 칸이 격자 ON 상태로 연속 5프레임 인식 + 라벨 폭 ≥ 화면 폭 8% → 1회 촬영 (목록의 ✅ 누르면 재촬영)
- 내보내기: 사진 zip + `촬영기록.csv` (칸번호, 파일명, 촬영시각)

## 구조

| 파일 | 내용 |
|---|---|
| `src/lib/detect.js` | 흰 라벨 검출 (HSV 흰색 마스크 → 닫힘 연산 → 연결 성분 → 가로세로비 2~6.5, 채움비 ≥ 0.6) |
| `src/lib/ocr.js` | tesseract.js OCR (라벨 폭 60px 이상, `^A-\d{1,2}-\d{1,2}$`, 신뢰도 80 이상) |
| `src/lib/grid.js` | 격자 추정 (열=a·x+b, 행=c·y+d, 두 점 RANSAC, 일치 3개 이상 시 ON) |
| `src/lib/pipeline.js` | 프레임 1장 처리 |
| `src/lib/store.js` | IndexedDB 저장, zip/csv 내보내기 |
| `src/App.jsx` | 화면, 파일 테스트/카메라 모드, 자동 촬영 |

`det.py`·`run.py` 원본은 PC에서 찾지 못해, 지시서 2절의 설명을 기준으로 구현했습니다.
밝기 기준은 고정값 대신 프레임별 자동값(상위 1% 밝기 − 40)을 씁니다. 투명 서랍 앞면(밝기 약 170)이 라벨(약 225~230)과 붙어 잡히는 문제 때문입니다.

## 1차 검증 결과 (참고 영상, PC, 0.1초 간격 282프레임)

| 대상 | 인식 구간 | 비고 |
|---|---|---|
| A-9-12 | 4.8~6.8초 | OCR로 직접 판독 |
| A-18-17 | 15.9~17.9초 | OCR, 앞뒤 끝 프레임은 격자 추정 |
| A-24-15 | 27.0~28.1초 | 주로 격자 추정 (OCR로 직접 읽힌 건 27.4초) |

- 오인식(엉뚱한 칸 녹색 표시): 0건. OCR 오판독 2종(`A-7-1`, `A-19-1`)은 격자와 맞지 않아 걸러지고, 위치로 올바른 번호가 붙었습니다.
- 처리시간(PC): 중앙값 56ms, 상위 10% 193ms, 최대 378ms
- 폰 처리시간: 미측정

### 인식 가능 거리 (전체 화면 인식 가능 여부)

| 화면상 라벨 폭 (1280px 영상 기준) | OCR 채택률 |
|---|---|
| 20~59px (벽 전체가 보이는 거리) | OCR 불가 (판독 시도 기준 미만) |
| 60~79px | 2% |
| 80~99px | 13% |
| 100px 이상 | 20% |

- 벽 전체가 보이는 거리에서는 라벨 폭이 약 20~24px여서 **글자 판독이 불가능**합니다. 라벨 사각형 자체는 검출됩니다(한 화면에 약 240개).
- 인식이 된 거리는 **화면에 칸이 가로 약 4~6개, 세로 4~6행 보일 때**입니다.
